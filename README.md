# Vitafreeze · Marketing

Repositorio de trabajo de marketing de **Vitafreeze**, empresa peruana de alimentos y bebidas saludables con planta en Arequipa.

> ⚠️ Este repositorio es **público**. No subir datos de clientes, IDs de cuentas publicitarias, presupuestos, costos ni métricas internas.

## Cómo pedirle algo a Claude

Abre una incidencia (Issues → New issue) y escribe `@claude` seguido del pedido. Ejemplo:

```
@claude crea en contenido/ 5 copys para Instagram de la recarga de agua a S/14
```

Claude trabaja en una rama y abre un PR para que lo revises antes de unirlo.
